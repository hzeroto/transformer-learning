# 作业 004：稳定的逐组 Softmax

## 目标

只实现 `stable_softmax.py` 中的函数，把已讲过的 Softmax 写成可靠的张量代码。
不修改测试，不需要写训练循环或手推 Softmax 的导数。

```text
输入 scores: (..., N)
输出 weights: 与输入同 shape、dtype、device

例如 (B, T, N)：每个固定的 (b, t) 对自己的 N 个候选独立归一化。
前置轴也可以为空，此时输入 (N,) 表示一组分数。
```

这里的 `...` 是形状记号，表示任意数量的前置轴，不需要在函数签名中填写。

## 要求

- 使用基础 Tensor 运算：取最大值、减法、指数、求和和除法。
- 必须沿最后一个轴独立归一化，不能使用整个张量的最大值或整个张量的总和。
- 不调用 `torch.softmax`、`Tensor.softmax` 或其他现成 Softmax 封装。
- 不修改输入，不转成 Python 数字后重建 Tensor，保留自动求导计算图。
- 假设输入均在 CPU 上，dtype 是 float32 或 float64，至少有一个轴且各轴非空，
  输入元素均为有限值。不要求额外校验，也不处理 mask、NaN 或正负无穷输入。
- 很小的概率下溢为 0 可以接受；不能让一整组指数都变成 0 后再用 0 作分母。
  不需要通过额外加一个小常数来修补分母。

## API 提示

这些操作已经在讲解中出现，可以查提示，不需要背 API 名称。

```python
x.amax(dim=-1, keepdim=True)  # 沿最后一个轴取最大值，保留该轴且长度变为 1
torch.exp(x)                 # 逐元素计算 e 的 x 次方
x.sum(dim=-1, keepdim=True)  # 沿最后一个轴求和，保留该轴且长度变为 1
```

`keepdim=True` 使每组的最大值或分母能广播回该组的所有候选。
`torch.Tensor` 是类型提示，不会自动检查输入。`raise NotImplementedError(...)`
是未完成的占位代码，完成实现后删除或替换它。

## 关键反例

```text
scores = [[ 1000, 1001],
          [-1000, -999]]

正确结果的两行相同，均约为 [0.268941, 0.731059]。
```

两行各有自己的分母。测试还会覆盖三维输入、每组加不同常数、单候选、
输入不被修改，以及返回值仍能参与自动求导。
自动求导测试使用带不同系数的概率加权和作为标量，再比较输入梯度；
你只需保留 Tensor 运算链，无需手写梯度。
测试中的官方 Softmax 只用于验收数值，不允许放进你的实现。
